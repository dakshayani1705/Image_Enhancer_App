📌 Image Enhancer Application (IEA)

📖 Overview
The Image Enhancer Application (IEA) is a web-based project that allows users to upload images and apply various enhancements such as resizing, cropping, grayscale conversion, and brightness/contrast adjustments. It provides a simple and interactive interface for real-time image processing.

🚀 Features
Upload and preview images
Crop and resize images
Convert images to grayscale
Adjust brightness and contrast
Download processed images
Responsive and user-friendly interface

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend / Processing: Python
Concepts Used: Image Processing, File Handling, UI Design

⚙️ How It Works
User uploads an image
Image is processed using Python-based logic
User selects desired transformations
Processed image is displayed instantly
User downloads the enhanced image

📊 Use Cases
Basic image editing tool
Learning project for image processing
Demonstrates frontend-backend integration

🧠 Key Learnings
Implemented image processing techniques using Python
Integrated frontend UI with backend logic
Handled user-uploaded files efficiently
Built an interactive web application
